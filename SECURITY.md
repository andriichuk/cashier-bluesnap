# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send the report to `andriichuk29@gmail.com` with reproduction steps and the affected version or commit.

Never include live BlueSnap credentials, full card data, security codes, or customer personal data in a report. Use synthetic values and the BlueSnap sandbox wherever possible.

## Supported versions

Until the first tagged release, security fixes are applied to the `main` branch only.
